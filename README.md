# Волна

Социальная сеть для русскоязычного рынка: лента коротких видео как в TikTok, истории и фото контактов как в Instagram и мессенджер как в Telegram — в одном приложении.

**Онлайн:** https://msggs.github.io/social-net/ — публикуется из `main` workflow `.github/workflows/static.yml` при каждом пуше.

## Что внутри

Приложение открывается сразу на **ленте**. Внизу панель: **Контакты · Лента · Чаты · Профиль**.

- **Лента**
  - вертикальные видео на весь экран, каждое прокручивается до конца, как в TikTok;
  - вкладки «Для вас» (рекомендации, каждый третий пост — от ваших контактов) и «Подписки»;
  - сверху истории контактов; при прокрутке они сворачиваются в плашку «Истории»;
  - фото-карусели контактов прямо в ленте с меткой «Ваш контакт»;
  - лайк двойным тапом, комментарии, «сохранить», отправка поста в чаты, подписка на автора;
  - публикация своих фото, видео и историй.
- **Истории**: прогресс-бары, тап влево/вправо, удержание — пауза, ответ на историю уходит в личный чат.
- **Контакты**: поиск по имени, нику или номеру; статус «в сети / был(а)»; добавление контакта; популярные авторы; профиль пользователя с сеткой публикаций и кнопкой «Написать».
- **Чаты как в Telegram**
  - папки «Все / Непрочитанные / Личные / Группы / Каналы», закрепление, архив, режим «без звука»;
  - черновики, галочки прочтения, «печатает…»;
  - ответы на сообщения, редактирование, удаление, фото, эмодзи;
  - карточки пересланных постов, группы и каналы;
  - долгое нажатие или правый клик открывает контекстное меню.
- **Профиль**: сетка публикаций, вкладки «Видео» и «Сохранённое», редактирование профиля.
- **Настройки** (в профиле, шестерёнка): уведомления, конфиденциальность (кто видит номер, истории, кто может писать), данные и память (автовоспроизведение, экономия трафика), оформление (светлая, тёмная или системная тема, цвет акцента, размер текста в чатах), устройства, выход.

Сейчас это фронтенд-прототип: данные демонстрационные (`src/data/mock.ts`), состояние хранится в `localStorage`, собеседники в чатах отвечают автоматически.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # проверка типов + production-сборка в dist/
```

Лучше всего смотреть с телефона или в режиме мобильного устройства в DevTools. На десктопе приложение показывается в рамке телефона.

Автономное демо без внешних сервисов (фото и видео генерируются локально, нужны Python с Pillow и numpy и ffmpeg):

```bash
npm run media:demo   # перегенерировать иллюстрации и ролики в public/media (они уже лежат в репозитории)
npm run build:demo   # сборка в dist-demo/, открывается с любого статического хостинга
```

## Стек

React 19 + TypeScript, Vite, React Router, Zustand (с persist), lucide-react. Без UI-фреймворков: стили в `src/index.css` на CSS-переменных.

```
src/
  pages/        экраны: лента, контакты, чаты, чат, профиль, настройки…
  components/   лента (VerticalFeed, PostItem), истории, нижние листы, навигация
  store/        useStore — данные и действия, useUI — открытые оверлеи
  data/mock.ts  демо-пользователи, посты, истории, чаты
  utils/        форматирование дат, плюрализация, сжатие фото
```
